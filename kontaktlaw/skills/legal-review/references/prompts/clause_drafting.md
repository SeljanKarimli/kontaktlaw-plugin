# Clause Drafting

Use the shared language, evidence and output rules in SKILL.md.

Check the whole document for equivalent protection before proposing a missing clause. Draft only protection material to the user objective. Label new rights and duties as proposals; do not invent agreed commercial parameters. Preserve governing-law and terminology consistency. Use clause_verification before delivering.

## Example

If a separate annex already provides a refund remedy, do not propose a duplicate; explain any actual gap.
