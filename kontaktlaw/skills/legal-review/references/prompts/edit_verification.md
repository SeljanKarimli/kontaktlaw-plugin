# Edit Verification

Use the shared language, evidence and output rules in SKILL.md.

Verify exact occurrence, replacement boundaries, surrounding syntax, references and intended effect. Grammar-only changes must preserve substance. Legal revisions may change rights or duties within the requested objective but must disclose the effect and unresolved commercial terms. Do not demand a substantive change when none is needed. An unchanged proposal can be reported as no change needed. Do not apply an edit to an ambiguous occurrence.

## Example

Adding a refund right fails a grammar-only check but can pass a buyer-protection revision check if requested and clearly labelled.
