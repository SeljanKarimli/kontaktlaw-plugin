# Web Research

Use the shared language, evidence and output rules in SKILL.md.

Search official sources with abstract legal concepts. Never include private document passages, personal identifiers or deal terms in queries. Prefer the official HTML or PDF URLs in corpus metadata; if one cannot be read, try the other. Confirm article text, exceptions, effective dates and amendment notes before making a current-law claim. If unavailable, label the answer as based on the dated bundled snapshot. Retrieval failure is not proof that a legal rule does not exist.

## Example

When official sources cannot be read, explain the snapshot limitation and omit claims of current verification.
