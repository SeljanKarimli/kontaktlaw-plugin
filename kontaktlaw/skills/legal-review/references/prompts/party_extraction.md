# Party Extraction

Use the shared language, evidence and output rules in SKILL.md.

Extract legal parties from operative introductory and signature clauses. Distinguish representatives, banks, beneficiaries and service providers from contracting parties. Use roles and exact names supported by the document; do not select a client from brand recognition. Ask which party to protect when the user has not selected one, offering general review. If an annex conflicts with the main document, report the ambiguity.

## Example

A fictional contract names Cedar Buyer LLC and Willow Supplier LLC; an account at Example Bank does not make that bank a contracting party.
