# Active plugin prompts

One canonical set; these prompts run with the host model. Historical website variants are retained only in the repository archive and are not runtime instructions.

- [risk_review](prompts/risk_review.md): Complete document, selected party or general-review instruction.
- [party_extraction](prompts/party_extraction.md): Document and any user-selected perspective.
- [grammar](prompts/grammar.md): Text to correct.
- [chat](prompts/chat.md): User question and relevant supplied document.
- [query_condense](prompts/query_condense.md): Ambiguous follow-up and relevant conversation context.
- [summary](prompts/summary.md): Supplied document and requested level of detail.
- [explanation](prompts/explanation.md): Selected clause and surrounding document.
- [rewrite](prompts/rewrite.md): Existing clause, user objective and editing mode.
- [edit_verification](prompts/edit_verification.md): Original span, surrounding clause, proposed replacement and authorized editing mode.
- [web_research](prompts/web_research.md): Legal question, explicit jurisdiction and date requirement.
- [clause_drafting](prompts/clause_drafting.md): User-requested protection, selected party and full document.
- [clause_verification](prompts/clause_verification.md): Proposed clause, drafting objective and full document.
